# Amsterdam Airbnb: Data Visualization in R

Week 2 task for the Virtual R Data Analyst Internship.

## Contents
- week2_visualization.Rmd: R Markdown source (code and narrative)
- week2_visualization.docx: the knitted report with 14 figures
- figures/: the 11 main charts as separate 300 dpi PNG files

## Data
Inside Airbnb, Amsterdam, detailed listings file (listings.csv)
https://insideairbnb.com/get-the-data/
The data file is not included. Download it and put it next to the .Rmd file.

## How to run
1. Install R and RStudio.
2. install.packages(c("tidyverse", "scales", "patchwork", "lubridate"))
3. Open week2_visualization.Rmd, set the working directory to its folder, and click Knit to Word.

## Charts
Histogram, bar chart, boxplot, lollipop, scatter plot, line charts, heatmap,
100% stacked bar, map, correlation chart, dumbbell chart, dashboard,
plus one base R and one lattice example.
